Storage and lifecycle behavior

Soft shutdown and reboot request guest OS actions. Hard shutdown and reboot stop the guest instantly.

The writable ext4 disk retains session changes across reboots. Reset image discards disk changes and preserves 9p.

Source selection clears and repopulates 9p while running or halted. Open guest fids can still reference deleted files; use cd /shared to leave a deleted directory.

Editor changes sync on blur or after 30 seconds of inactivity. External changes replace editor contents immediately. Boot output stays in terminal history.

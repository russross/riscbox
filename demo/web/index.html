Storage and lifecycle behavior

Soft controls request guest action and return immediately. Hard controls stop or restart execution. Boot restarts from the boot payloads. Reset image halts, cold-resets RAM, discards the HTTP disk overlay, and boots; it preserves 9p. Clear/reload 9p preserves the disk. Destroy releases both stores.

The EROFS base is read-only. Files in the tmpfs-backed home and temporary directories disappear on every boot, including reboot. Files in 9p and the HTTP disk overlay survive reboot until explicitly reset.

Selecting a file does not read it. Copy to editor reads its current bytes. Save to 9p replaces the file with the editor text. Refresh tree lists the current namespace. Nothing saves automatically or checks for lost edits.
